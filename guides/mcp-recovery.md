# MCP가 안 될 때 · 증상부터 확인하기

[Agent Stack Brief](../README.md) · **한국어** · [English](mcp-recovery.en.md) · [검색 실습](web-validation.md)

**순서:** 등록 → 서버 시작 → 도구 호출 → 결과 확인. 실패한 단계 하나만 고르세요. 등록 목록에 있다는 것과 연결 성공, 업무 성공은 서로 다릅니다.

- [서버가 목록에 없어요](#server-missing)
- [서버·브라우저가 시작되지 않아요](#browser-start)
- [연결됐지만 호출이 실패해요](#call-failure)
- [검색 결과가 엉뚱해요](#search-no-match)

**먼저 멈출 것:** 반복 설치·전체 설정 덮어쓰기·캐시 전체 삭제·보안 제한 해제. 변경 작업이 시간 초과됐다면 이미 실행됐을 수 있으므로 현재 상태부터 확인하세요.

<a id="server-missing"></a>

## 1. 서버가 목록에 없어요

**확인:** 지금 사용하는 클라이언트와 설정 형식이 맞나요? Codex는 TOML, 다른 클라이언트는 서로 다른 JSON 키를 사용할 수 있습니다. 플러그인이 제공하는 서버와 직접 등록한 서버도 구분하세요.

Codex에서 등록을 확인하는 읽기 전용 명령:

```bash
codex mcp list
```

**기대 상태:** 원하는 서버 이름이 등록 목록에 나옵니다. 없다면 [환경별 설정](web-validation.md)을 대조하고, 기존 항목은 중복 등록하지 마세요. 설정 변경 후에는 사용하는 클라이언트의 재시작·재연결 절차를 따르세요. 조직에서 관리하는 설정은 관리자에게 확인합니다.

**다음:** 목록에 있으면 [시작 단계](#browser-start)로 이동합니다. 목록만으로 성공이라고 보고하지 마세요.

<a id="browser-start"></a>

## 2. 서버·브라우저가 시작되지 않아요

**확인:** 클라이언트의 서버 로그에서 첫 오류를 찾으세요. 로컬 STDIO 서버라면 터미널과 클라이언트가 같은 Node/npm을 보는지 확인합니다.

```bash
node --version
npm --version
```

Chrome 도구라면 Chrome 설치·실행 가능 여부도 확인하세요. 일반 프로필을 강제로 종료하지 말고 실습의 별도 세션을 사용합니다. 원격 HTTP 서버에는 Node 확인이 해당하지 않을 수 있습니다.

**기대 상태:** 서버가 연결됨으로 표시되고 도구 목록을 불러옵니다. Codex의 `startup_timeout_sec`는 시작 대기, `tool_timeout_sec`는 호출 대기이므로 같은 문제로 다루지 마세요. timeout을 늘리기 전에 실행 경로·오류 원인부터 확인합니다.

**다음:** 오류와 환경을 [공식 Chrome 문제 해결](https://github.com/ChromeDevTools/chrome-devtools-mcp/blob/main/docs/troubleshooting.md) 또는 해당 서버 안내와 대조하세요. 권한·샌드박스 해제가 필요하다는 안내를 발견해도 승인 없이 적용하지 마세요.

<a id="call-failure"></a>

## 3. 연결됐지만 호출이 실패해요

**확인:** 실제 제공된 도구 이름과 필수 입력이 맞나요? 인증 오류, 도구 없음, 시간 초과를 구분하고 마지막 호출의 오류 문구를 보관하세요. 로그를 공유할 때 토큰·쿠키·개인 정보는 제거합니다.

**기대 상태:** 허용된 공개 자료의 읽기 요청 하나가 성공하고 결과 본문이 돌아옵니다. 도구를 선택할 수 없다면 호스트의 활성화·허용 목록이나 조직 정책을 확인하세요. 인증은 해당 서비스의 공식 절차로만 진행합니다.

**다음:** 읽기 요청만 안전하게 다시 확인합니다. 저장·발송·배포 같은 변경 호출은 서버 측 상태를 확인하기 전 재실행하지 마세요. 해결되지 않으면 아래 양식을 남깁니다.

<a id="search-no-match"></a>

## 4. 검색 결과가 엉뚱해요

**확인:** 검색 성공은 원하는 답을 찾았다는 뜻이 아닙니다. 제품명·설정 키로 질의를 좁히고 결과의 문서 제목·대상 제품을 확인하세요.

**기대 상태:** 질문을 직접 설명하는 공식 본문을 조회할 수 있습니다. 검색 결과에 없다면 관련 공식 페이지 안의 링크로 찾아가세요. [실제 Docs MCP 사례](cases/docs-mcp-review.md)에서도 이 경로를 사용했습니다.

**다음:** 끝내 확인할 수 없으면 ‘미확인’과 시도한 경로를 보고합니다. 문서에서 명령을 읽은 것과 실제 실행한 결과를 섞지 마세요.

## 도움을 요청할 때 복사하세요

```text
환경·클라이언트·버전:
서버 이름·버전(알 수 없다면 미노출):
실패 단계: 등록 / 시작 / 호출 / 결과
마지막 요청과 오류(비밀 제거):
기대 결과 / 실제 결과:
이미 확인한 항목:
외부 시스템에 변경이 있었는지: 확인 / 미확인
```

**확인 범위 · 2026-10-19:** [공식 MCP 설정](https://learn.chatgpt.com/docs/extend/mcp)과 Chrome 문서를 검토해 작성한 진단 안내입니다. 검색 결과가 부정확한 경로는 실제 사례로 확인했으며, 나머지 장애를 모두 재현한 것은 아닙니다.
